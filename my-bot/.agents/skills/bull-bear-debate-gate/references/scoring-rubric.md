# 五维评分细则 (Scoring Rubric)

> 用于 `bull-bear-debate-gate` 技能的评分标准化。每个维度 1-5 分，必须基于具体证据。

---

## 一、技术面（权重 30%）

### 多头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 明确的上升趋势，多重技术信号共振 | MA5>MA10>MA20>MA60 多头排列 + KDJ金叉 + MACD金叉 + 放量突破关键位 |
| 4 | 上升趋势中，大部分指标偏多 | 价格 > MA20 > MA60，KDJ 金叉，RSI 50-70，温和放量 |
| 3 | 趋势不明确，部分指标偏多 | 价格在 MA20 附近震荡，KDJ 中性，RSI 40-60 |
| 2 | 偏弱，但有个别积极信号 | 下跌趋势中，出现底背离或缩量企稳 |
| 1 | 明确下降趋势，无任何积极信号 | MA5<MA10<MA20<MA60 空头排列 + KDJ死叉 + 持续放量下跌 |

### 空头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 明确的下降趋势，多重风险信号 | 连续一字跌停、均线空头排列加速发散、MACD 绿柱放大 |
| 4 | 下降趋势中，大部分指标偏空 | 价格 < MA20 < MA60，KDJ 死叉，RSI < 30 但未反弹 |
| 3 | 方向不明，有部分偏空信号 | 价格在阻力位受阻，KDJ 高位死叉，布林带收窄 |
| 2 | 偏强，但有个别风险信号 | 上升趋势中，RSI > 70 超买，或出现顶背离 |
| 1 | 明确上升趋势，无任何风险信号 | 均线多头排列完美发散，所有指标一致看多 |

### 关键检查项

- [ ] 价格与 MA5/MA10/MA20/MA60/MA250 的关系
- [ ] 均线排列方向（多头/空头/缠绕）
- [ ] KDJ 位置和方向（金叉/死叉/超买/超卖）
- [ ] RSI 位置（超买 > 70 / 超卖 < 30）
- [ ] 布林带位置（上轨/中轨/下轨）和带宽变化
- [ ] 成交量配合（放量上涨/缩量下跌 vs 放量下跌/缩量上涨）
- [ ] 关键支撑/阻力位
- [ ] 近期是否出现一字跌停/涨停（流动性风险）

## 二、资金面（权重 25%）

### 多头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 多路资金共振流入，持续放量 | 北向连续净买入 + 主力净流入 + 成交量持续放大 + 换手率健康 |
| 4 | 资金面偏多，有明确流入 | 北向近 5 日净买入，成交放量，换手率 > 5% 且价升量增 |
| 3 | 资金面中性 | 北向小幅波动，成交量正常，无明确方向 |
| 2 | 资金面偏空，但有局部改善 | 北向流出但幅度减小，缩量企稳 |
| 1 | 资金全面流出 | 北向连续大额净卖出，主力出逃，缩量或放量下跌 |

### 空头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 资金恐慌性出逃 | 北向单日净卖出 > 50 亿 + 主力大幅流出 + 放量暴跌 |
| 4 | 资金持续流出 | 北向连续 5 日净卖出，成交量萎缩，无人接盘 |
| 3 | 资金面中性偏空 | 北向小幅流出，成交量一般 |
| 2 | 资金面偏多，但有隐忧 | 北向流入但力度减弱，或放量滞涨 |
| 1 | 资金全面流入 | 北向连续大额买入，主力持续流入，量价配合完美 |

### 关键检查项

- [ ] 北向资金近 5 日净买入/卖出金额
- [ ] 成交量趋势（放大/缩小）与价格的关系
- [ ] 换手率水平（异常高/异常低/正常）
- [ ] 主力资金流向（如有数据）
- [ ] 大单/小单成交比例
- [ ] 与同板块其他标的的资金流向对比

## 三、基本面（权重 20%）

### 多头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 基本面全面优秀，业绩加速增长 | 营收增速 > 30% + 净利润增速 > 30% + 行业景气向上 + 竞争优势明显 |
| 4 | 基本面良好，稳定增长 | 营收增速 15-30%，PE 在历史中位数以下，行业景气 |
| 3 | 基本面一般，无明显亮点或风险 | 营收增速 5-15%，PE 合理，行业中性 |
| 2 | 基本面偏弱，但有改善迹象 | 营收增速 < 5%，但亏损收窄或新产品即将放量 |
| 1 | 基本面恶化 | 营收负增长，持续亏损，行业衰退 |

### 空头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 基本面全面恶化 | 营收大幅下滑、连续亏损、债务危机、行业崩盘 |
| 4 | 基本面明显走弱 | 营收增速转负、利润率压缩、行业景气下行 |
| 3 | 基本面中性偏弱 | 增速放缓，竞争加剧，估值偏高 |
| 2 | 基本面良好，但有隐忧 | 高增长但估值过高，或行业周期见顶风险 |
| 1 | 基本面全面优秀 | 高增长、低估值、强竞争优势、行业龙头 |

### 关键检查项

- [ ] 最近季度营收增速（YoY）
- [ ] 最近季度净利润增速（YoY）
- [ ] PE/PB 估值在历史分位数中的位置
- [ ] 行业景气度（上行/下行/平稳）
- [ ] 公司竞争优势（护城河）是否稳固
- [ ] 近期是否有财报/业绩预告事件

## 四、情绪面（权重 15%）

### 多头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 市场情绪极度乐观，全面共振 | 涨停家数 > 100、恐慌指数低位、题材全面爆发、政策强力催化 |
| 4 | 市场情绪偏乐观 | 多数板块上涨、赚钱效应好、政策利好 |
| 3 | 市场情绪中性 | 涨跌互现、板块轮动、无明确方向 |
| 2 | 市场情绪偏悲观 | 多数板块下跌、恐慌蔓延、但局部有抵抗 |
| 1 | 市场情绪极度恐慌 | 千股跌停、恐慌指数飙升、系统性抛售 |

### 空头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 极度恐慌，系统性风险 | 科创50 单日 -6.5%、跌停家数 > 200、流动性危机 |
| 4 | 明显恐慌 | 主要指数大跌 > 2%、多数板块下跌、资金避险 |
| 3 | 情绪中性偏弱 | 指数小跌，板块分化，缺乏主线 |
| 2 | 情绪偏乐观，但有隐忧 | 指数上涨但量能不足，或高位震荡 |
| 1 | 极度乐观 | 全面牛市、涨停潮、全民炒股 |

### 关键检查项

- [ ] 主要指数涨跌和幅度（沪深300、科创50、恒生）
- [ ] 涨跌停家数对比
- [ ] 市场成交量（全市场）
- [ ] 题材热度和持续性
- [ ] 政策面消息（利好/利空）
- [ ] 市场是否存在系统性风险（如美股暴跌传导）

## 五、宏观面（权重 10%）

### 多头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 宏观环境全面利好 | 降息周期 + 流动性宽松 + 财政扩张 + 汇率稳定 + 外部环境友好 |
| 4 | 宏观环境偏利好 | 货币政策中性偏松、经济温和复苏、外部风险可控 |
| 3 | 宏观环境中性 | 政策平稳、经济数据好坏参半 |
| 2 | 宏观环境偏不利 | 货币政策收紧预期、经济放缓、外部风险上升 |
| 1 | 宏观环境全面利空 | 加息周期 + 流动性紧缩 + 经济衰退 + 汇率暴跌 + 外部危机 |

### 空头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 宏观危机 | 金融危机、战争、政策突变、汇率崩盘 |
| 4 | 宏观环境明显不利 | 加息预期升温、流动性收紧、经济数据恶化 |
| 3 | 宏观环境中性偏紧 | 政策观望期、通胀压力、外部不确定性 |
| 2 | 宏观环境偏利好，但有风险 | 降息预期但通胀反弹、地缘政治风险 |
| 1 | 宏观环境全面利好 | 宽松周期、经济强劲、外部稳定 |

### 关键检查项

- [ ] 美联储政策方向（降息/加息/暂停）
- [ ] 国内货币政策（降准/降息/MLF/LPR）
- [ ] 人民币汇率走势
- [ ] 关键经济数据（PMI、CPI、GDP）
- [ ] 美股走势（隔夜传导）
- [ ] 地缘政治风险

## 六、财报面（权重 10%，仅 earnings_season 模式）

### 多头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 财报全面超预期 | 营收+利润双超预期 + 指引大幅上调 + 财报后跳空涨停 |
| 4 | 财报较好 | 营收或利润超预期、指引小幅上调、股价正面反应 |
| 3 | 财报符合预期 | 业绩与预期一致，指引不变，股价反应平淡 |
| 2 | 财报略低于预期 | 轻微 miss，但长期逻辑未破坏 |
| 1 | 财报严重不及预期 | 大幅 miss + 指引下调 + 财报后暴跌 |

### 空头评分标准

| 分数 | 标准 | 典型证据 |
|---|---|---|
| 5 | 财报暴雷 | 业绩大幅 miss + 指引大幅下调 + 财报后连续跌停 |
| 4 | 财报明显不及预期 | 营收和利润均 miss，指引下调，股价大跌 |
| 3 | 财报中性偏弱 | 部分指标 miss，但整体可控 |
| 2 | 财报超预期，但有隐忧 | 业绩好但毛利率下降，或一次性收益占比高 |
| 1 | 财报全面超预期 | 业绩完美，无任何瑕疵 |

## 评分示例

### 示例 1：德明利 001309（2026-07-30）

| 维度 | 多头 | 空头 | 多空分析 |
|---|---|---|---|
| 技术面 | 2 | 5 | 多头：RSI=12 极度超卖，今日涨停。空头：均线空头排列，7/15-7/17 一字跌停，趋势完全破坏。 |
| 资金面 | 2 | 4 | 多头：今日放量涨停，有资金承接。空头：7/21 放量反弹一日游后被埋，前车之鉴。 |
| 基本面 | 2 | 2 | 多头：存储行业长期受益于 AI。空头：PE/PB 为 null，可能亏损。数据不足，均打 2 分。 |
| 情绪面 | 1 | 5 | 多头：涨停提振。空头：科创50 -6.5%，半导体板块全面崩跌，市场恐慌。 |
| 宏观面 | 2 | 3 | 多头：国内流动性中性。空头：美股前夜暴跌 -2.2%，传导至 A 股。 |

**Net_Score = (2×0.3 + 2×0.25 + 2×0.2 + 1×0.15 + 2×0.1) - (5×0.3 + 4×0.25 + 2×0.2 + 5×0.15 + 3×0.1)**
**= 1.85 - 3.95 = -2.10**

> 🔴 红灯 — 空头显著占优，不建仓。与回测结果（所有策略 Abandon）一致。

### 示例 2：完美世界 002624（2026-07-30 建仓）

| 维度 | 多头 | 空头 | 多空分析 |
|---|---|---|---|
| 技术面 | 4 | 3 | 多头：3日底部确认完成（+5.0%→-1.2%缩量→+4.3%放量），10.30 支撑有效。空头：大盘暴跌，冲高回落长上影。 |
| 资金面 | 3 | 3 | 多头：放量确认。空头：大盘资金流出，系统性风险。 |
| 基本面 | 3 | 2 | 多头：游戏版号常态化。空头：前期 -15,389 亏损，基本面未必支撑。 |
| 情绪面 | 2 | 3 | 多头：游戏板块相对抗跌。空头：市场整体恐慌。 |
| 宏观面 | 2 | 3 | 多头：中性。空头：美股大跌传导。 |

**Net_Score = (4×0.3 + 3×0.25 + 3×0.2 + 2×0.15 + 2×0.1) - (3×0.3 + 3×0.25 + 2×0.2 + 3×0.15 + 3×0.1)**
**= 2.85 - 2.80 = +0.05**

> 🟠 橙灯 — 多空几乎均衡。按建仓规则，橙灯应观望不建仓。但 3 日底部确认形态完整，且入场价 10.30 接近止损 9.50（风险可控），可降级为半仓（750 股）。实际执行了 1,500 股，属于标准仓位，略显激进。
